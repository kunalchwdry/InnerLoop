# InnerLoop

**InnerLoop** is an AI-powered productivity and study management platform designed to help students organize their studies, habits, tasks, timetable, and progress in one place.

## 🚧 Project Status

**Under Active Development**

InnerLoop is currently being rebuilt from scratch as part of our Smart India Hackathon preparation.

## ✨ Current Features

* 👤 User profile
* 📅 Timetable management
* ✅ Task management
* 🔄 Habit management
* 📊 Progress tracking
* ✔️ Mark tasks and habits as completed
* 💾 JSON-based local data storage

## 🛠️ Current Tech Stack

* Python
* JSON
* Git
* GitHub

## 🔮 Planned Features

* FastAPI backend
* Database integration
* AI assistant
* Groq API integration
* AI-powered timetable management
* Personalized study planning
* Progress analytics
* Web/mobile interface
* Authentication

## 🧠 AI Vision

The long-term goal is to allow users to interact with InnerLoop using natural language.

For example:

> "Schedule DSA tomorrow at 7 PM."

The AI will understand the request and use InnerLoop's internal functions to safely update the user's timetable.

## 🌟 What is InnerLoop?

**InnerLoop** is an AI-powered platform designed specifically for students.

Instead of switching between different applications for tasks, habits, studies, courses, fitness, focus and communication, InnerLoop brings everything into **one connected ecosystem**.

> **One loop for your entire student journey.**

# 🧠 Why InnerLoop?

Students currently use different apps for different parts of their life.

| Need | Typical Solution |
|---|---|
| Tasks | Todo apps |
| Habits | Habit trackers |
| Learning | Course platforms |
| Timetable | Calendar apps |
| Focus | Focus apps |
| Fitness | Fitness apps |
| Community | Social platforms |
| AI assistance | AI chatbots |
